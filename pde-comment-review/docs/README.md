# pde-comment-review Documentation

pde-comment-review lets you decide, one screen at a time, on the
comments an AI wrote in Go code.

Pick the page for what you need to do:

- Run a review, from the AI's proposals to the commit:
  [Review comments](how-to/review-comments.md).
- Look up a command, a key, what the write checks, or where reviews are
  saved: [Commands, files, and keys](reference/commands-files-and-keys.md).
- Let an agent harness start the MCP server:
  [The MCP server](reference/commands-files-and-keys.md#the-mcp-server).
- Write proposals as an AI: the
  [comment-review skill](../../ai/skills/comment-review/SKILL.md).

Pages in `how-to/` are steps to follow, and pages in `reference/` are
facts to look up. Paths that start with `internal/` are inside
`pde-comment-review/`, paths that start with `~` are in your home
directory, and every other path starts at the top of the repository.
