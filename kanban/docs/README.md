# Kanban card documentation

`card` keeps kanban cards as notes in the Obsidian vault. Commands on
these pages run in any shell where `card` is on `PATH`.

- New to cards? Start with the tutorial,
  [Your first card](tutorials/first-card.md).
- To put a session that is already running onto the board, read
  [Adopt work already under way](how-to/adopt-running-work.md).
- To look up a command, stage, move, field or Log line, read the
  [card reference](reference/card.md).
- To learn why cards and plans are kept apart, and what the staff agent
  will do, read [Cards, plans and the staff agent](explanation/cards-and-plans.md).
